## Projetos

### [Homelab](https://github.com/fajremvp/homelab)

Ambiente pessoal de infraestrutura e serviços autohospedados, utilizando Linux, Proxmox VE, Docker e Ansible. Inclui automação de configuração, redes, observabilidade, segurança e rotinas de backup.

### [nixos-config](https://github.com/fajremvp/nixos-config)

Mantenho uma configuração declarativa do NixOS utilizando Nix Flakes e Home Manager, aplicando conceitos de Infrastructure as Code (IaC) diretamente no ambiente desktop.

O projeto automatiza o gerenciamento do sistema operacional, pacotes, drivers e configurações pessoais, eliminando processos manuais e garantindo reprodutibilidade, versionamento e recuperação através de rollbacks.

### [cantina-udesc-doo2](https://github.com/fajremvp/cantina-udesc-doo2)

Projeto de extensão desenvolvido na disciplina de Programação Orientada a Objetos II (DOO2) da UDESC.

Desenvolvemos em equipe um sistema desktop de gerenciamento da cantina universitária em Java utilizando arquitetura MVC, com o objetivo de digitalizar o fluxo de pedidos e substituir processos baseados em papel e WhatsApp, propondo uma solução para melhorar a organização do atendimento em horários de pico e o controle de demanda e estoque.

O desenvolvimento foi organizado com Kanban, branches por funcionalidade e revisão por Pull Requests. Utilizamos GitHub Actions para integração contínua e JPA/Hibernate com SQLite para persistência dos dados.
